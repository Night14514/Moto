# MotoTalk - Сводка проекта

## Обзор

Полное кроссплатформенное приложение Push-to-Talk (PTT) для голосовой связи двух мотоциклистов с голосовым управлением, интеграцией музыки и премиум тёмным интерфейсом.

## Технологический стек (всё бесплатно и self-hosted)

### Backend
- **Node.js 18** - Среда выполнения
- **Express** - Веб-фреймворк
- **Socket.io** - Сигнализация WebSocket
- **better-sqlite3** - Встроенная база данных
- **Docker** - Контейнеризация

### Frontend
- **Flutter 3.19+** - Кроссплатформенный фреймворк
- **flutter_webrtc** - Реализация WebRTC
- **socket_io_client** - WebSocket клиент
- **speech_to_text** - Локальное распознавание речи
- **audio_manager** - Управление аудио
- **provider** - Управление состоянием

## Реализованные ключевые возможности

### ✅ Основная функциональность
- Push-to-Talk (PTT) с кнопкой удержания для разговора
- Режим голосового управления с командами (Приём, Пуск, Стоп, Отбой)
- P2P потоковая передача аудио через WebRTC
- Сервер сигнализации WebSocket
- Авторизация по PIN-коду (4 цифры)
- Автоматическое переподключение с экспоненциальной задержкой

### ✅ Аудио возможности
- Пауза/возобновление музыки при активации PTT
- Поддержка Bluetooth-наушников
- Подавление шума WebRTC
- Подавление эха
- Автоматическая регулировка усиления
- Фильтрация шума ветра (через WebRTC)

### ✅ Поддержка платформ
- Android 11+ с foreground service
- iOS 16+ с режимом фонового аудио
- Bluetooth-наушники (AirPods, Galaxy Buds и др.)
- Поддержка работы в фоновом режиме

### ✅ UI/UX
- Премиум тёмная тема с синими/неоновыми акцентами
- Большие области касания для использования в перчатках
- Плавные анимации с flutter_animate
- Индикаторы статуса в реальном времени
- Визуализация статуса соединения
- Индикаторы активности собеседника

### ✅ Надёжность
- Автоматическое переподключение (WebSocket + WebRTC)
- Обнаружение изменения сети
- Обработка перезапуска сервера
- Сохранение состояния соединения
- Экспоненциальная задержка при переподключении

### ✅ Безопасность
- TLS для соединений WebSocket
- DTLS для рукопожатия WebRTC
- SRTP для шифрования медиа
- Без облачных сервисов (полностью self-hosted)
- Без платных API

## Развертывание

### Сервер (Kali Linux)
```bash
cd /home/night/blprj/server
docker-compose up -d
```

### Мобильное приложение
```bash
cd /home/night/blprj/app
flutter pub get
flutter run
```

## Конфигурация

### URL сервера
Отредактируйте `app/lib/config.dart`:
```dart
static const String serverUrl = 'http://YOUR_PC_IP:3000';
```

### Голосовые команды
Отредактируйте `app/lib/config.dart`:
```dart
static const List<String> voiceCommandsStart = ['приём', 'пуск'];
static const List<String> voiceCommandsStop = ['стоп', 'отбой'];
```

## Ограничения платформ

### Android
- Требуется foreground service для фонового аудио
- Bluetooth SCO должен быть явно включён
- Требуется управление аудио-фокусом
- Разрешения: RECORD_AUDIO, BLUETOOTH_CONNECT, FOREGROUND_SERVICE

### iOS
- Требуется CallKit для оптимальной фоновой работы
- Разрешения Bluetooth в Info.plist
- Конфигурация режима фонового аудио
- VoIP push-уведомления для пробуждения

Подробнее см. [PLATFORM_LIMITATIONS.md](docs/PLATFORM_LIMITATIONS.md).

## Требования к ресурсам

### Сервер
- CPU: Одного ядра достаточно
- RAM: <100 МБ
- Хранилище: <50 МБ
- Сеть: <1 Мбит/с на пользователя

### Мобильное устройство
- RAM: <200 МБ
- Хранилище: ~100 МБ размер приложения
- Батарея: ~5-10% в час использования
- Сеть: ~500 Кбит/с на пользователя

## Известные ограничения

1. **Максимум 2 пользователя** - Архитектура оптимизирована ровно для 2 пользователей
2. **Без поддержки групп** - Не предназначено для масштабирования
3. **Локальное распознавание речи** - Требует поддержки устройства
4. **Только русские команды** - В данный момент настроено на русский
5. **Требуется одна сеть** - Сервер и клиенты в одной LAN (или проброс портов)

## Следующие шаги

1. **Обновите URL сервера** в `app/lib/config.dart` на IP вашего ПК
2. **Запустите сервер** с `docker-compose up -d`
3. **Соберите приложение** для Android/iOS
4. **Протестируйте на реальных устройствах** с Bluetooth-наушниками
5. **Протестируйте в реальных условиях езды**
6. **Оптимизируйте на основе обратной связи**
