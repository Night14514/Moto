# Быстрый старт

## Предварительные требования

### Сервер (Kali Linux)
- Установлен Docker
- Установлен Docker Compose
- Порт 3000 доступен

### Мобильное устройство (Android/iOS)
- Flutter SDK 3.19+
- Android Studio (для Android) или Xcode (для iOS)
- Физическое устройство с Bluetooth-наушниками
- Мобильный интернет

## Шаг 1: Запуск сервера

```bash
cd /home/night/blprj/server
cp .env.example .env
docker-compose up -d
```

Проверьте, что сервер запущен:
```bash
docker-compose ps
docker-compose logs -f
```

Получите IP-адрес вашего ПК:
```bash
ip addr show
```

## Шаг 2: Настройка мобильного приложения

Отредактируйте `app/lib/config.dart`:
```dart
static const String serverUrl = 'http://YOUR_PC_IP:3000';
```

Замените `YOUR_PC_IP` на ваш фактический IP-адрес (например, `192.168.1.100`).

## Шаг 3: Сборка и запуск мобильного приложения

### Android
```bash
cd /home/night/blprj/app
flutter pub get
flutter devices
flutter run
```

### iOS
```bash
cd /home/night/blprj/app
flutter pub get
cd ios
pod install
cd ..
open ios/Runner.xcworkspace
# Запустите из Xcode
```

## Шаг 4: Регистрация пользователей

1. Откройте приложение на первом телефоне
2. Введите имя пользователя и 4-значный PIN-код
3. Нажмите "Создать аккаунт"
4. Повторите на втором телефоне с другим PIN-кодом

## Шаг 5: Подключение и тестирование

1. Оба пользователя должны видеть статус "Онлайн"
2. Подключите Bluetooth-наушники
3. Включите музыку на телефоне
4. Удерживайте большую кнопку PTT
5. Музыка должна поставить на паузу
6. Говорите в микрофон
7. Другой пользователь должен вас слышать
8. Отпустите кнопку
9. Музыка должна возобновиться

## Шаг 6: Тестирование голосового управления (опционально)

1. Нажмите селектор режима "Голос"
2. Нажмите кнопку для начала прослушивания
3. Скажите "Приём" или "Пуск" для начала передачи
4. Скажите "Стоп" или "Отбой" для остановки

## Устранение неполадок

### Сервер недоступен
- Проверьте брандмауэр: `sudo ufw allow 3000`
- Проверьте IP-адрес
- Убедитесь, что телефон и ПК в одной сети

### Bluetooth не работает
- Проверьте, что наушники сопряжены
- Предоставьте разрешения Bluetooth
- Протестируйте с другими приложениями

### Проблемы со звуком
- Проверьте разрешения микрофона
- Протестируйте в тихой обстановке
- Проверьте сетевое подключение

Подробнее см. [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
