# MotoTalk - Голосовая связь PTT для мотоциклистов

Кроссплатформенное приложение Push-to-Talk для двух мотоциклистов с голосовым управлением и интеграцией музыки.

## Возможности

- **Push-to-Talk (PTT)**: Удерживайте кнопку для разговора, отпустите для остановки
- **Голосовое управление**: Голосовые команды ("Приём", "Пуск", "Стоп", "Отбой")
- **Интеграция музыки**: Автоматическая пауза/возобновление музыки во время звонков
- **Низкая задержка**: WebRTC с задержкой <300 мс
- **Подавление шума**: Фильтрация шума ветра для использования на мотоцикле
- **Автоматическое переподключение**: Автоматическое переподключение после проблем с сетью/сервером
- **Премиум UI**: Тёмная тема с синими/неоновыми акцентами для использования в перчатках

## Технологический стек

- **Backend**: Node.js + Express + Socket.io + WebRTC
- **Frontend**: Flutter + flutter_webrtc + speech_to_text
- **База данных**: SQLite (встроенная)
- **Контейнеризация**: Docker Compose

## Быстрый старт

### Сервер (Kali Linux)

```bash
cd server
docker-compose up -d
```

### Мобильное приложение (Android/iOS)

```bash
cd app
flutter pub get
flutter run
```

## Требования

- Сервер: Kali Linux с Docker
- Android 11+ или iOS 16+
- Bluetooth-наушники с микрофоном
- Мобильный интернет
