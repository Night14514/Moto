# Руководство по устранению неполадок

## Проблемы с сервером

### Сервер не запускается

**Симптом**: Контейнер Docker не запускается

**Решения**:
1. Проверьте, занят ли порт 3000:
   ```bash
   sudo lsof -i :3000
   ```
2. Убейте процесс использующий порт 3000 или измените порт в `.env`
3. Проверьте логи Docker:
   ```bash
   docker-compose logs server
   ```
4. Пересоберите контейнер:
   ```bash
   docker-compose down
   docker-compose build
   docker-compose up -d
   ```

### Сервер недоступен с телефона

**Симптом**: Телефон не может подключиться к серверу

**Решения**:
1. Проверьте IP сервера:
   ```bash
   ip addr show
   ```
2. Обновите `serverUrl` в `app/lib/config.dart`
3. Проверьте брандмауэр:
   ```bash
   sudo ufw status
   sudo ufw allow 3000
   ```
4. Убедитесь, что телефон и ПК в одной сети
5. Попробуйте использовать локальный IP ПК вместо имени хоста

### Высокое использование CPU сервером

**Симптом**: Сервер использует 100% CPU

**Решения**:
1. Нормально во время рукопожатия WebRTC - должно стабилизироваться
2. Проверьте наличие циклов соединения:
   ```bash
   docker-compose logs -f server
   ```
3. Перезапустите сервер если проблема сохраняется:
   ```bash
   docker-compose restart
   ```

## Проблемы с мобильным приложением

### Приложение не устанавливается на Android

**Симптом**: Установка не удаётся

**Решения**:
1. Включите "Установка из неизвестных источников" в настройках
2. Проверьте версию Android (минимум 11)
3. Очистите хранилище если недостаточно места
4. Попробуйте установку через ADB:
   ```bash
   adb install app-release.apk
   ```

### Приложение не устанавливается на iOS

**Симптом**: Установка не удаётся

**Решения**:
1. Доверяйте разработчику в Настройки > Основные > VPN и управление устройствами
2. Проверьте версию iOS (минимум 16)
3. Используйте Xcode для установки
4. Убедитесь, что учётная запись Apple Developer действительна

### Микрофон не работает

**Симптом**: Не удаётся передавать аудио

**Решения**:
1. Проверьте разрешения микрофона в настройках приложения
2. Сначала протестируйте со встроенным микрофоном
3. Проверьте, не использует ли микрофон другое приложение
4. Перезагрузите телефон
5. Переустановите приложение

### Bluetooth не подключается

**Симптом**: Аудио не маршрутизируется на Bluetooth

**Решения**:
1. Убедитесь, что наушники сопряжены с телефоном
2. Проверьте разрешения Bluetooth в настройках приложения
3. Протестируйте наушники с другими приложениями
4. Отключите/включите Bluetooth
5. Перезагрузите телефон
6. Проверьте, поддерживают ли наушники профиль HFP/HSP

### Музыка не ставится на паузу

**Симптом**: Музыка продолжается во время PTT

**Решения**:
1. Проверьте, поддерживает ли музыкальное приложение аудио-фокус
2. Попробуйте другое музыкальное приложение (Яндекс Музыка, Spotify)
3. Проверьте разрешения аудио-фокуса
4. Протестируйте с системным музыкальным плеером
5. Перезапустите музыкальное приложение

### Плохое качество аудио

**Симптом**: Аудио прерывистое или низкого качества

**Решения**:
1. Проверьте силу сетевого соединения
2. Протестируйте на WiFi vs мобильной сети
3. Проверьте использование CPU сервера
4. Уменьшите расстояние между пользователями
5. Проверьте силу сигнала Bluetooth
6. Попробуйте другие наушники

### Высокая задержка

**Симптом**: Заметная задержка в аудио

**Решения**:
1. Проверьте пинг сети до сервера
2. Протестируйте на более быстрой сети
3. Проверьте, использует ли WebRTC прямое P2P
4. Уменьшите качество аудио при необходимости
5. Проверьте расположение сервера

### Голосовые команды не распознаются

**Симптом**: Голосовые команды не работают

**Решения**:
1. Проверьте разрешения микрофона
2. Убедитесь, что выбран русский язык
3. Говорите чётко и громко
4. Сначала протестируйте в тихой обстановке
5. Проверьте доступность распознавания речи
6. Перезапустите приложение

### Приложение вылетает

**Симптом**: Приложение закрывается неожиданно

**Решения**:
1. Проверьте хранилище телефона
2. Обновите приложение до последней версии
3. Очистите кэш приложения
4. Переустановите приложение
5. Проверьте логи сбоев (Android: logcat, iOS: Xcode)
6. Сообщите о проблеме с моделью устройства и версией ОС

### Быстрый разряд батареи

**Симптом**: Батарея быстро разряжается

**Решения**:
1. Проверьте, не работает ли приложение в фоне без необходимости
2. Уменьшите яркость экрана
3. Закройте другие приложения
4. Используйте WiFi вместо мобильной сети когда возможно
5. Проверьте наличие циклов соединения
6. Обновите до последней версии

## Проблемы с соединением

### Не удаётся подключиться к собеседнику

**Симптом**: Показывает, что собеседник оффлайн

**Решения**:
1. Убедитесь, что оба пользователя зарегистрированы
2. Проверьте, что у обоих пользователей одинаковый URL сервера
3. Проверьте, что сервер запущен
4. Проверьте сетевое соединение на обоих телефонах
5. Перезапустите оба приложения
6. Перерегистрируйтесь при необходимости

### Соединение часто обрывается

**Симптом**: Соединение постоянно отключается

**Решения**:
1. Проверьте стабильность сети
2. Протестируйте на другой сети
3. Проверьте логи сервера на ошибки
4. Убедитесь, что автоподключение включено
5. Проверьте настройки энергосбережения телефона
6. Отключите VPN если включён

### Соединение WebRTC не удаётся

**Симптом**: P2P соединение не устанавливается

**Решения**:
1. Проверьте доступность STUN серверов
2. Попробуйте другую сеть
3. Проверьте настройки брандмауэра
4. Убедитесь, что оба пользователя могут достичь сервера
5. Перезапустите оба приложения
6. Проверьте логи сервера на ошибки ICE

## Проблемы с аудио

### Эхо в аудио

**Симптом**: Слышите свой собственный голос

**Решения**:
1. Подавление эха WebRTC должно обрабатывать это
2. Проверьте, не используете ли вы динамик вместо наушников
3. Убедитесь, что наушники правильно подключены
4. Уменьшите громкость на телефоне
5. Проверьте настройки аудио в приложении

### Фоновый шум

**Симптом**: Слишком много фонового шума

**Решения**:
1. Подавление шума WebRTC включено по умолчанию
2. Переместитесь в более тихое место если возможно
3. Отрегулируйте положение микрофона
4. Используйте наушники с лучшим подавлением шума
5. Говорите ближе к микрофону

### Шум ветра

**Симптом**: Шум ветра мешает аудио

**Решения**:
1. Используйте ветрозащиту на микрофоне если доступна
2. Расположите микрофон подальше от ветра
3. Используйте шлем с лучшей защитой от ветра
4. Отрегулируйте настройки подавления шума
5. Рассмотрите использование других наушников

## Специфичные для платформ проблемы

### Фоновые ограничения Android

**Симптом**: Приложение перестаёт работать в фоне

**Решения**:
1. Убедитесь, что foreground service запущен
2. Проверьте настройки оптимизации батареи
3. Добавьте приложение в белый список оптимизации батареи
4. Проверьте настройки режима Doze
5. Убедитесь, что уведомление показывается

### Фоновые ограничения iOS

**Симптом**: Приложение перестаёт работать в фоне

**Решения**:
1. Убедитесь, что режим фонового аудио включён
2. Проверьте, правильно ли настроен CallKit
3. Убедитесь, что VoIP push-уведомления включены
4. Проверьте настройки обновления фоновых приложений iOS
5. Протестируйте с заблокированным экраном

## Получение помощи

Если проблемы сохраняются:

1. Проверьте логи сервера: `docker-compose logs -f server`
2. Проверьте логи приложения (Android: `adb logcat`, iOS: Xcode)
3. Документируйте точные шаги для воспроизведения
4. Запишите модель устройства, версию ОС, версию приложения
5. Проверьте условия сети
6. Попробуйте на другом устройстве/сети если возможно

## Распространённые сообщения об ошибках

### "Authentication failed" (Ошибка авторизации)
- Проверьте правильность PIN-кода
- Убедитесь, что пользователь зарегистрирован
- Проверьте, что сервер запущен

### "Connection timeout" (Тайм-аут соединения)
- Проверьте сетевое соединение
- Проверьте правильность URL сервера
- Проверьте настройки брандмауэра

### "Microphone permission denied" (Отказано в разрешении микрофона)
- Предоставьте разрешение микрофона в настройках
- Переустановите приложение при необходимости

### "Bluetooth not available" (Bluetooth недоступен)
- Включите Bluetooth на телефоне
- Сопрягите наушники с телефоном
- Проверьте разрешения Bluetooth

### "Speech recognition not available" (Распознавание речи недоступно)
- Проверьте, поддерживает ли устройство распознавание речи
- Убедитесь, что русский язык установлен
- Перезагрузите устройство
