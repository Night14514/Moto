# Ограничения платформ - Android и iOS

## Ограничения Android

### Фоновое аудио
- **Проблема**: Android ограничивает захват аудио в фоне
- **Решение**: Используйте Foreground Service с уведомлением
- **Реализация**: 
  - Создайте foreground service для записи аудио
  - Показывайте постоянное уведомление
  - Запросите разрешения RECORD_AUDIO и FOREGROUND_SERVICE

### Приоритет микрофона Bluetooth
- **Проблема**: Система может отдавать приоритет встроенному микрофону вместо Bluetooth
- **Решение**: Явно установите аудио-режим и предпочтение Bluetooth
- **Реализация**:
  ```dart
  await audioManager.setMode(AudioMode.communication);
  await audioManager.setBluetoothScoOn(true);
  ```

### Управление аудио-фокусом
- **Проблема**: Другие приложения (музыкальные плееры) могут не освобождать аудио-фокус
- **Решение**: Правильно запрашивайте и управляйте аудио-фокусом
- **Реализация**:
  - Запрашивайте AUDIOFOCUS_GAIN_TRANSIENT для PTT
  - Освобождайте фокус после окончания PTT
  - Обрабатывайте потерю аудио-фокуса от других приложений

### Фоновые ограничения (Android 11+)
- **Проблема**: Фоновое выполнение ограничено
- **Решение**: Foreground service с правильными разрешениями
- **Требуемые разрешения**:
  - RECORD_AUDIO
  - FOREGROUND_SERVICE
  - FOREGROUND_SERVICE_MICROPHONE (Android 14+)
  - BLUETOOTH_CONNECT (Android 12+)
  - INTERNET
  - WAKE_LOCK

### Режим Doze
- **Проблема**: Устройство может войти в режим Doze, останавливая сеть
- **Решение**: Используйте частичный WakeLock для соединения WebSocket
- **Реализация**: Получайте WakeLock при подключении, освобождайте при отключении

## Ограничения iOS

### Фоновое аудио
- **Проблема**: iOS строго ограничивает фоновое аудио
- **Решение**: Используйте AVAudioSession с соответствующей категорией
- **Реализация**:
  ```swift
  try AVAudioSession.sharedInstance().setCategory(
    .playAndRecord,
    mode: .voiceChat,
    options: [.allowBluetooth, .allowBluetoothA2DP]
  )
  ```

### Интеграция CallKit
- **Проблема**: iOS может прерывать VoIP звонки без CallKit
- **Решение**: Интегрируйте CallKit для обработки звонков на системном уровне
- **Преимущества**:
  - Интеграция с системным UI
  - Лучшая обработка фона
  - Приоритет над другим аудио

### Аудио-сессия Bluetooth
- **Проблема**: iOS требует явного разрешения Bluetooth
- **Решение**: Запросите разрешения Bluetooth в Info.plist
- **Требуемые разрешения**:
  - NSBluetoothAlwaysUsageDescription
  - NSBluetoothPeripheralUsageDescription (iOS 13+)

### Жизненный цикл приложения
- **Проблема**: Приложение может быть приостановлено в фоне
- **Решение**: Используйте VoIP push-уведомления для пробуждения
- **Реализация**: 
  - Зарегистрируйтесь для VoIP push
  - Обрабатывайте push для пробуждения приложения
  - Переподключайтесь при активации приложения

### Управление памятью
- **Проблема**: iOS может завершать фоновые приложения
- **Решение**: Минимальное использование памяти, сохранение состояния
- **Реализация**:
  - Сохраняйте состояние соединения
  - Быстрое переподключение при запуске приложения
  - Очищайте ресурсы когда не нужны

## Совместимость Bluetooth-наушников

### AirPods
- **Работает**: Все модели (AirPods, Pro, Max)
- **Примечания**: Автоматическое переключение может вызывать проблемы, отключите при необходимости

### Samsung Galaxy Buds
- **Работает**: Большинство моделей
- **Примечания**: Может потребоваться приложение Samsung для оптимальных настроек

### Xiaomi Buds
- **Работает**: Большинство моделей
- **Примечания**: Проверьте приложение для настроек приоритета микрофона

### Huawei FreeBuds
- **Работает**: Большинство моделей
- **Примечания**: Может потребоваться приложение Huawei для конфигурации

### Универсальные Bluetooth-наушники
- **Работает**: Большинство с профилем HFP/HSP
- **Требования**: Должны поддерживать Hands-Free Profile (HFP) или Headset Profile (HSP)

## Распространённые проблемы и решения

### Музыка не ставится на паузу
- **Причина**: Аудио-фокус не управляется правильно
- **Решение**: Реализуйте правильное использование API аудио-фокуса на обеих платформах

### Микрофон не переключается
- **Причина**: Bluetooth SCO не активирован
- **Решение**: Явно включите Bluetooth SCO на Android, установите правильную аудио-сессию на iOS

### Обрыв фонового соединения
- **Причина**: Фоновые ограничения ОС
- **Решение**: Foreground service (Android) + CallKit/VoIP push (iOS)

### Высокая задержка
- **Причина**: Маршрутизация сети, выбор кодека
- **Решение**: Используйте кодек Opus, оптимизируйте ICE-кандидаты, прямое P2P соединение

### Шум ветра
- **Причина**: Окружение мотоцикла
- **Решение**: Подавление шума WebRTC + пользовательский фильтр шума ветра
