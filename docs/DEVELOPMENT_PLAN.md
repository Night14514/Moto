## Критерии успеха

### MVP
- [ ] Два пользователя могут подключиться
- [ ] PTT работает с задержкой <500 мс
- [ ] Аудио разборчиво
- [ ] Музыка ставится на паузу/возобновляется правильно
- [ ] Bluetooth-наушники работают

### Продакшен
- [ ] Задержка <300 мс (цель 50-150 мс)
- [ ] Голосовые команды работают надёжно
- [ ] Автоматическое переподключение работает
- [ ] Батарея работает 4+ часа
- [ ] Работает в реальных условиях езды
- [ ] Нет сбоев во время сессий 2+ часа
